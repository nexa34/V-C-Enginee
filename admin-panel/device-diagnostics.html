Known Issues & Solutions
First-party app consent error
Active

Problem: The current client_id is a Microsoft first-party application. Personal accounts cannot consent to first-party apps.
Solution: Use a third-party Azure AD application (MAB: 29d9ed98-a469-4536-ade2-f981bc1d605e) or register your own app in Azure Portal.

Code expired for personal accounts
Expected

Behavior: Personal accounts show "code expired" after multiple failed attempts. This is normal Microsoft behavior to prevent brute force.
Solution: Clear browser cache/cookies or use incognito mode for new attempts.
